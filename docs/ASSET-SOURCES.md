Vista source atlases use 10 columns and 7 rows. Classic/Hearts/Seasons store number cards in Clubs, Diamonds, Hearts, Spades order, followed by court cards. Large Print instead uses sequential suits in Clubs, Diamonds, Spades, Hearts order and ranks 2–King, Ace. The preparation script normalizes all decks to Clubs, Diamonds, Hearts, Spades and Ace–King.

Vista uses the preserved `FELTX2.JPG`, `BROWNFELTX2.JPG`, `HEARTSX2.JPG`, `NATUREX2.JPG` and `REDFELTX2.JPG` resources from [The Spriters Resource background archive](https://www.spriters-resource.com/pc_computer/solitairewindowsvista7/asset/573977/), retrieved 2026-09-08. ZIP SHA-256: `60EBFD44DB73B25F32CA88DFBAB6FF01BCC76DB7B91EEE5FBCFD76E8D5F2BDEF`. Green felt image SHA-256: `DD9177062BBD72DC65BE424F7C7A37A9D9811B1B4D64C133C5C4A5F70C3431D9`. The renderer samples the 1600 × 992 image area, excluding padding where present.

Version 0.3 adds original game-specific resources from [Spider asset 144032](https://www.spriters-resource.com/pc_computer/windowsxpcardgames/asset/144032/) and [FreeCell asset 103851](https://www.spriters-resource.com/pc_computer/windowsxpcardgames/asset/103851/). The Spider sheet is credited to extractor Nova Stuart Hale. `tools/prepare-game-art.ps1` copies the original card pixels, spider back, felt tile, About image and two FreeCell king portraits into embedded resources. No downloaded program is executed. The classic Spider resources are used for Me and XP; no Me binary was available to prove resource identity between those releases.

Seven additional animation images from Daniel Ricci's `assets/images/decks` directory supply Robot, Castle, Palm and card-hand frames. Their timing follows [Microsoft KB Q66960](https://jeffpar.github.io/kbarchive/kb/066/Q66960/): timed games only, continuous Robot/Castle, approximately 30-second Palm and 15-second card-hand cycles. The frame cadence is reconstructed.

Gameplay references: [Michael Keller's FreeCell FAQ](https://www.solitairelaboratory.com/fcfaq.html) documents Microsoft auto-home, the XP deal-number expansion and old supermove limitations; its [tutorial](https://www.solitairelaboratory.com/tutorial.html) documents the old click-to-select and empty-column prompt. Microsoft deal 1 is checked in full in the test suite. Klondike keep-score behavior follows [Microsoft KB 72925](https://www.betaarchive.com/wiki/index.php/Microsoft_KB_Archive/72925).

Window frames and controls are composed by this project. Classic chrome is drawn; Vista uses the image resources described under version 0.8 below. Classic text uses the host's installed `vgasys.fon` and `sserife.fon`, parsed as bitmap data. No font files are bundled or installed. The parser follows Microsoft's [font-file format documentation](https://jeffpar.github.io/kbarchive/kb/065/Q65123/). A system font fallback remains available if the raster resources are absent.

Version 0.6 added game icons and six Spider WAV resources from [xp-cards at commit 33a6d49](https://github.com/esc0rtd3w/xp-cards/tree/33a6d492ffa63f0b16b1ad982930c16d367f6bbb). The source fingerprints are in `MECHANICS-AUDIT.md`. `tools/read-period-resources.mjs` reads the PE resource directory as bytes, decodes MENU/ACCELERATOR tables, writes data-only ICO/WAV files and exports controls JSON under ignored `references/Mechanics`. No downloaded program or DLL is run or embedded. Pre-XP uses 4-bit icon groups where available. Classic Spider retains the extracted XP icons; Vista reused them through 0.7 and now uses the Vista images below. Reuse does not establish that every original icon was identical. WAV 124 is used for successful classic Spider actions and 129 for its win; the event mapping and timing are reconstructed. The host EXE's own Solitude icon is still project-drawn.

Version 0.7 extends the same data-only parser to standard/extended DIALOG and counted UTF-16 STRINGTABLE records. FreeCell's STATS, GAMENUM, MOVECOL, YOUWIN and Options (505) bounds, captions, font specification and controls inform its corrected dialogs. No additional binary code is executed or bundled. At nonintegral display sizes, classic MS Sans Serif text uses the host's scalable Microsoft Sans Serif substitute; 2000/XP use Tahoma and Vista uses Segoe UI. Font files remain unbundled.

Version 0.8 adds 41 PNG frame/button/glyph/reflection resources from [VistaThemePlasma commit 888afc2](https://github.com/aeroshell-desktop/vistathemeplasma/tree/888afc21db58be32e13dec0e00b19309284feb7c). The archive identifies these resources as Microsoft artwork. Only images are embedded; its Linux theme code and installation steps are not used. Its AGPL-3.0 license is retained in `docs/licenses/vistathemeplasma-AGPL-3.0.txt` for provenance. Original Vista game icon PNGs are preserved by Wikimedia: [Solitaire](https://en.wikipedia.org/wiki/File:Solitaire_Icon_(Vista).png), [FreeCell](https://en.wikipedia.org/wiki/File:FreeCell_Icon_(Vista).png), [Spider](https://en.wikipedia.org/wiki/File:SpiderSolitaire_Icon_(Vista).png). These replace the XP icons previously reused by Vista. Files are hashed in `references/Frames/manifest-v080.json`. Frame measurements and primary Microsoft reference captures are documented in [FRAME-ALIGNMENT.md](FRAME-ALIGNMENT.md). No theme, executable, font or Windows component was installed.

## Version 0.9 additions (9 September 2026)

- Twenty WAV resources from [The Sounds Resource asset 442489](https://sounds.spriters-resource.com/pc_computer/solitairewindowsvista7/asset/442489/), downloaded via its public archive link. SHA-256 `909AD32EDB4A382C03FB17DCAB91F956C732D03F9E2DA783960BA848C3ECFA05`. Only WAV data is embedded. Names identify card movement, illegal moves, hints, Undo, FreeCell wins and Spider fireworks; the event dispatch and mixing behavior are reconstructed, not certified against every original game build.
- The 10-point `vgasys.fon` System strike and 8-point `sserife.fon` MS Sans Serif strike are extracted from local `C:/Windows/Fonts` as standalone FNT data and embedded. This supersedes the host-font lookup and fractional-scale substitution described above for Windows 3.x/95/98/Me. It freezes the available legacy strikes; it does not prove that this host's FNT bytes equal each original OS release. 2000/XP/Vista scalable fonts still come from the host.
- Long Zheng's [4 September 2006 Vista screencasts](https://istartedsomething.com/20060904/windows-vista-screencast-bundled-games/) were recovered from the Internet Archive. Solitaire capture: `20070103172400`, original URL `http://www.istartedsomething.com:80/uploads/solitaire.mov`; Spider capture: `20110623181723`, original URL `http://www.istartedsomething.com/uploads/spidersolitaire.mov`. They show **Vista RC1 build 5600**, not a verified RTM build. They establish falling/shattering Solitaire cards, continuing Spider fireworks, small in-game tips, and the Solitaire Game Won score/bonus/results layout. Playback speed varies during gameplay. The win effects are independently rendered approximations of the observed choreography. The recordings and decoding tools are analysis-only; none are embedded.
- FreeCell `-1` and `-2`: the preserved XP file SHA-256 `BA517F623B778F4B842F559EA344CB64D3CAE9DE172AECFA4E330C733BAAD601` contains explicit branches at VA `01003233` through `010032D1`. Reading the instructions as data gives `-1`'s odd ascending/even descending ranks in C/D/H/S columns; `-2`'s reversed suits with A,K,Q,J,10,9,8 on the left and 7..2 on the right. The first layout also matches [this preserved Windows 95 screenshot](https://www.freecellonline.com/images/unsolvable-freecell-win95.png). [Jim Horne's firsthand interview](https://www.hey.gg/blog/freecell) confirms the deliberate negative deals in NT/95/XP. The code independently constructs these fixed layouts. No Microsoft executable was run, modified or embedded. Vista negative deals remain unverified and unavailable.

Exact resource fingerprints are in [FIDELITY-RESOURCE-HASHES-0.9.0.json](FIDELITY-RESOURCE-HASHES-0.9.0.json).
